What Makes it Different
Production-Grade Design Decisions
These aren't notebook experiments. Each decision was made with real-world deployment constraints in mind — and each is enforced in code, not documentation.
⚙️
MCP: Swappable Tool Transport
The 5 tools are exposed via Model Context Protocol. When mcp is importable, FastMCP handles calls. When absent (CI, system Python), core_agent silently probes import mcp and falls back to direct LangChain @tool imports — same tool surface, zero warnings, zero crashes. Swap to a remote MCP microservice by changing one config line.
🛡️
Two-Stage Safety Guardrails
Stage A keyword filter runs in microseconds to catch obvious misuse before an LLM call is made. Stage B uses GPT-4o-mini as a low-cost intent classifier for nuanced cases. PII (Aadhaar, PAN, mobile) is regex-masked before any log write. No raw PII ever reaches storage. Escalation ceiling breach triggers the handoff tool automatically — enforced in code.
🔄
Two-Layer RLHF
Layer 1 injects within-session feedback signals for immediate course correction. Layer 2 calls update_adaptive_policy() to persist learnings cross-session into adaptive_policy.json. The agent genuinely improves from real usage across sessions — not just one-shot prompt tuning. 16 RLHF adaptive tests verify the feedback loop actually changes agent behavior.
🔢
424-Test Suite
226 core tests covering all 5 tools, agent, safety, and retrieval pipeline. 182 coverage tests for edge cases — including ceiling breaches, malformed inputs, and PII edge cases. 16 RLHF adaptive tests. Integration tests run against real ChromaDB instances, not mocks — a deliberate choice after discovering mock-heavy tests were passing while real behavior was wrong.
