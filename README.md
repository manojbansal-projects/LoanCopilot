# AI-Powered Loan Origination Copilot

**IIT Madras AI Capstone · Scenario 2: Banking · Track A: LangChain**

A conversational AI agent that guides retail bank customers through early-stage loan origination for 4 products (Home, Personal, MSME, New Car). Provides indicative eligibility, EMI estimates, document checklists, and policy-grounded answers via RAG — all observable through self-hosted Langfuse.

---

## Quick Start

```bash
# 1 — Install dependencies
pip install -r requirements.txt

# 2 — Configure environment
cp .env.example .env
# Edit .env: add OPENAI_API_KEY + Langfuse keys

# 3 — Ingest policy documents into ChromaDB
python scripts/ingest_documents.py

# 4a — CLI agent
python scripts/run_agent.py

# 4b — Streamlit web UI (Phase 8+)
streamlit run deployment/app.py
```

## Tech Stack

- **LLM:** OpenAI GPT-4o (agent) · GPT-4o-mini (safety classifier)
- **Framework:** LangChain AgentExecutor (ReAct)
- **Vector store:** ChromaDB persistent
- **Embeddings:** OpenAI text-embedding-3-small
- **Observability:** Langfuse self-hosted (Docker Compose)
- **UI:** Streamlit (Phase 8+)

> LangSmith and Arize Phoenix are excluded — see `docs/engineering_justification.md`.

---

## Key Constraints

- `OPENAI_API_KEY` is required for all phases beyond Phase 2
- Policy documents are **synthetic** — educational demo, not official bank policy
- All logs are PII-masked before write (`safety/pii_filter.py`)
- English only; localization is out of scope for this prototype
